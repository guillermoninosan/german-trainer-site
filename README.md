# German Trainer — standalone installable app (PWA)

This is the "own apartment" version of the trainer: a small self-hosted website that
installs to your home screen with its own icon, works fully offline from a cold start
(open it in airplane mode, even after a restart), and still syncs your progress between
your phone and laptop automatically once you sign in with Google on each.

It reuses the exact same trainer engine as the Claude-hosted version (same lessons,
same spaced repetition, same Match mode) — only the delivery and sync mechanism changed.

## Part A — one-time setup (~10 minutes, you only do this once)

You need two free accounts: one to *host* the site (Netlify), one to *sync* your
progress (Firebase). Neither needs a credit card.

### A1. Create the Firebase project (sync)
1. Go to https://console.firebase.google.com, sign in with your Google account, click
   **"Add project"**. Name it anything (e.g. "german-trainer"). Skip Google Analytics
   (not needed) and click **Create**.
2. In the left sidebar: **Build → Authentication → Get started**. Click **Google** in
   the sign-in providers list, toggle it **Enable**, pick a support email, **Save**.
3. In the left sidebar: **Build → Firestore Database → Create database**. Choose
   **Production mode**, pick any location close to Zurich (e.g. `eur3 (europe-west)`),
   **Enable**.
4. Still in Firestore, open the **Rules** tab, delete the default text, and paste the
   contents of `firestore.rules` (in this folder) in its place. Click **Publish**.
   This is what makes sure only you can ever read or write your own progress.
5. Back in the project **Settings (gear icon) → General**, scroll to "Your apps",
   click the **`</>`** (web) icon, give it any nickname, **do not** check Firebase
   Hosting, click **Register app**. It shows a code block starting with
   `const firebaseConfig = { apiKey: "...", ... }` — send me those values (paste the
   whole object) and I'll bake them into the app and rebuild it for you. Nothing in
   that config is secret; it's fine to share it with me in chat.
6. One more thing to do *after* you have your site's URL from Part B: come back to
   **Authentication → Settings → Authorized domains** and add your Netlify domain
   (e.g. `german-trainer-guille.netlify.app`) so Google Sign-In is allowed to run
   there. (`localhost` is already allowed by default, for testing.)

### A2. Create the Netlify site (hosting)
1. Go to https://app.netlify.com, sign up free (email or GitHub).
2. Once logged in, you'll see a big dashed box that says **"Drag and drop your site
   output folder here"**. I'll give you a zip of the finished `dist/` folder — unzip
   it once, then drag that unzipped folder onto that box. Netlify uploads it and gives
   you a URL immediately, e.g. `random-name-123.netlify.app`.
3. Optional: **Site settings → Change site name** to something memorable, e.g.
   `german-trainer-guille` → your URL becomes `german-trainer-guille.netlify.app`.
4. Copy that URL and do step A1.6 above (add it to Firebase's authorized domains).

### A3. Install it on your devices
- **iPhone**: open the Netlify URL in Safari → Share button → **"Add to Home
  Screen"**. It now behaves like a real app icon, opens full-screen, no browser bar.
- **Laptop**: open the URL in Chrome → click the install icon (⊕ or a little monitor
  icon) in the address bar → **Install**. Or Chrome menu → "Cast, save and share" →
  "Install page as app".
- On first open on each device, tap **Sign in with Google** (shown on the home screen
  and under Progress → Sync) once. After that it stays signed in and syncs quietly.

That's it — from then on, whenever I rebuild the trainer with new vocabulary, I'll send
you a new zip; you unzip it and drag the folder onto Netlify's dashboard again (same
site, it just redeploys in place, same URL, same install, progress untouched since it
lives in Firestore/your account, not in the files).

## Part B — what's inside (for rebuilding)

```
pwa/
  index.template.html   - the real source: full HTML doc + PWA meta tags + Firebase
                           Auth/Firestore sync code, with DATA and FIREBASE_CONFIG
                           left as placeholders
  manifest.json          - installability metadata (name, icons, colors)
  service-worker.js      - offline app-shell cache (cache-first + background refresh),
                           cache name auto-versioned by make_pwa.py on every build
  icons/, favicon.png     - generated by make_icons.py (accent-blue "DE" monogram,
                           matches the trainer's existing --accent color #1f5fbf)
  firebase_config.json   - NOT committed to the Project (contains Guille's project's
                           config values) - created locally each session from what he
                           sends, used only at build time
  firestore.rules        - security rules to paste into the Firebase console (Part A1.4)
  make_pwa.py            - build script: embeds data.json + firebase_config.json into
                           index.template.html -> dist/index.html, copies manifest/
                           service-worker/icons into dist/, auto-bumps the service
                           worker's cache version from a hash of the build so every
                           redeploy forces installed devices to refresh
  dist/                  - build output, ready to zip and drag onto Netlify
```

### Rebuilding (weekly, when new class material comes in)
1. In `trainer-src/`, add the new rows to `nouns.txt` / `verbs.txt` / `words.txt` /
   `sentences.txt` / `grammar.py` (see `trainer-src/README.md` for the exact formats -
   unchanged from before).
2. `cd trainer-src && python3 build_data.py` -> regenerates `data.json` (fix any
   ERROR from the assertions before continuing).
3. `cd ../pwa && python3 make_pwa.py` -> regenerates `dist/`.
4. Zip `dist/` and deliver it (`SendUserFile`) so Guille can drag it onto Netlify.

### Why this exists / what changed from the Claude Artifact version
The Claude Artifact (`https://claude.ai/artifact/Cnryk4WGX5o7fgEpLnpyRk`, still live)
can't use a service worker, so it needs network just to open at all - fine at home,
not fine on a plane in airplane mode. This standalone version fixes exactly that: same
trainer engine, same lessons, same Match mode, same spaced repetition, but now with a
real offline-first app shell (works from a cold start with zero signal) and sync that
rides on Firestore's own offline cache instead of requiring a live connection. The
trade-off is the one-time setup above (two free accounts) instead of "it just works
because it's on claude.ai" - Guille explicitly chose this trade-off over staying on
the Artifact or going all the way to a native iOS App Store app.

The Artifact stays live as a no-setup fallback (e.g. open the link on any device that
isn't one of Guille's own) but is no longer the primary tool once this is set up.
